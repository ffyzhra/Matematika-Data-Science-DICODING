# Mathematics for Data Science: Dicoding Submission

Final submission for Dicoding's *Belajar Matematika untuk Data Science* class. Three problems implemented from scratch in Python. Each one comes as a notebook (`.ipynb`) and a script (`.py`).

| #   | Problem                                                                                                          | Concepts                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 1   | [Distributions & Naive Bayes](./soal-1-distribusi-dan-algoritma-naive-bayes.ipynb)                                | Random variables, uniform/normal distributions, probability, Naive Bayes classifier |
| 2   | [A/B testing for a recommendation system](./soal-2-sistem-rekomendasi-ab.ipynb)                                   | Simulated user data, hypothesis testing, t-test, p-values                          |
| 3   | [A/B testing for a software feature](./soal-3-software-dev-ab.ipynb)                                              | Experiment design, comparing groups, statistical significance                       |

`dataset_clustering_project/` holds the dataset used in the exercises.

## Tech stack

Python · NumPy · pandas · SciPy · Jupyter
